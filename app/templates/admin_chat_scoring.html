How Chat Scoring Works

🔍

Message Analysis

Every chat message is scanned for vulgarities, threats, and inappropriate content using pattern matching with leet-speak detection.

📊

Toxicity Scoring

Each message gets a toxicity score (0.0 - 1.0). Scores above 0.5 trigger a warning to the user in real-time.

👤

Behavior Score

Each user gets a behavior score (0-100) based on their overall chat history, factoring in frequency and severity of violations.

⚠️

Risk Levels

Users are classified as Good (80+), Caution (60-79), Warning (40-59), or Critical (below 40) based on behavior score.
