💡 What is OpenShare?

OpenShare is a secure file transfer and storage platform designed to provide encrypted data handling and authenticated access for sensitive documents.

🆓 Is account registration free?

Yes, everyone can register for an account completely free of charge.

👥 Who can use this platform?

The platform is currently available to authorized members of the OpenShare team and registered users within the organization.

📤 How do I upload a file?

Users can upload files through the main dashboard by clicking the "Upload" button and selecting the desired document.

🔍 Are my uploads scanned for threats?

Yes, every file uploaded to OpenShare is automatically scanned by our integrated VirusTotal background worker to detect and quarantine malicious content.

📏 What is the upload size limit?

The current maximum file size is 500MB per upload.

📎 Which file types are allowed?

We support documents, images, videos and archives to maintain system security.

📥 How do I download a file?

You will need a unique 16-character access code to download files securely.

⏰ How long do codes last?

Codes expire after 24 hours and a new one is generated after each download.

📋 How do I manage file requests?

Under the approval section, you can choose to request or respond to file requests from other users.

🔐 How is my data encrypted?

We use AES-256 for files at rest and TLS 1.3 for data in transit.

🔒 Is my data encrypted during transfer?

Yes, we use secure protocols to ensure that all data moving between your browser and our servers is encrypted and protected from interception.

🛡️ Does the system scan for viruses?

Yes, all uploads undergo a malware integrity check via VirusTotal.

🗝️ How are passwords stored?

We use Argon2id secure salted hashing to store all credentials.

⚠️ Can I disable security features?

No, security features like MFA and encrypted storage are mandatory to maintain our high security standards.

🌐 Recommended browsers?

Chrome, Firefox, or Edge are highly recommended for the best experience.

✏️ How do I change my profile info?

Visit the profile page to update your details and preferences.

🗑️ Can I delete my account?

Yes, accounts can be deleted from your profile settings page.

🔄 How do I change my password?

Passwords can be changed from the profile settings page under security options.
