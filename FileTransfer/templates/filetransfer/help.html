1. What is MoveIt?

MoveIt is a secure file transfer and storage platform designed to provide encrypted data handling and authenticated access for sensitive documents.

2. Is account registration free?

Yes everyone can register for an account.

3. Who can use this platform?

The platform is currently restricted to authorized members of the MoveIt team and registered users within the organization.

4. How do I upload a file?

Users can upload files through the main dashboard by clicking the "Upload" button and selecting the desired document.

5. Are my uploads scanned for threats?

Yes, every file uploaded to MoveIt is automatically scanned by our integrated VirusTotal background worker to detect and quarantine malicious content.

1. What is the upload size limit?

The current maximum file size is 500MB per upload.

2. Which am i allowed to upload?

We supports documents, images, videos and archives to maintain system security.

3. How do I download a file?

You will need an unique 16-character access code to download.

4. How long do codes last?

Codes expire after 24 hours and generated after each download

5. How do i manage file requests?

Under approval, you can choose to request or respond to file requests.

1. How is my data encrypted?

We use AES-256 for files at rest and TLS 1.3 for data in transit.

2. Is my data encrypted during transfer?

Yes, we use secure protocols to ensure that all data moving between your browser and our servers is encrypted and protected from interception.

3. Does the system scan for viruses?

Yes, all uploads undergo a malware integrity check.

4. How are passwords stored?

We use secure salted hashing to store credentials.

5. Can I disable security features for my account?

No, security features like MFA and encrypted storage are mandatory requirements of the MoveIt platform to maintain our high security standards.

1. Recommended browsers?

Chrome, Firefox, or Edge are highly recommended.

2. How do I change my profile info?

Visit the profile page to update your details.

3. Can I delete my account?

Accounts can be deleted in profile.

4. How do i change my password?

Passwords can be changed in profile settings.
