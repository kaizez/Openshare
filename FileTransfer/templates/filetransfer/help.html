General Support

1. How do I contact support?

Email Admin Roy at admin@movelorh.sg or use the button below.

2. How do I change my profile info?

Visit the Settings page to update your details.

3. Is account registration free?

Yes, all cybersecurity students can register for an account.

4. What should I do if I forget my password?

Contact the system administrator for a manual password reset.

5. Can I delete my account?

Account deletion requests can be sent via the support email.

File Transfer Guides

1. What is the upload size limit?

The current maximum file size is 20MB per upload.

2. Which formats are allowed?

We allow .pdf, .txt, .png, and .jpg to maintain system security.

3. How do I share a file?

After uploading, you will receive a unique 16-character access code.

4. How long do links last?

File access codes are valid for 24 hours by default.

5. Can I see who downloaded my file?

Yes, check the "Access Logs" section in your My Files dashboard.

Security & Privacy

1. How is my data encrypted?

We use AES-256 for files at rest and TLS 1.3 for data in transit.

2. What is HSTS?

It forces your browser to use secure HTTPS connections only.

3. Does the system scan for viruses?

Yes, all uploads undergo a malware integrity check.

4. How are passwords stored?

We use secure salted hashing to store credentials.

5. What is a CSRF token?

It protects your session from unauthorized third-party actions.

System Requirements

1. Recommended browsers?

Chrome, Firefox, or Edge are highly recommended.

2. Do I need JavaScript?

Yes, JS is required for secure toggles and AI chatbot features.

3. What are session cookies?

Small files that keep you logged in; we use HttpOnly flags for safety.

4. What is 'nosniff'?

A header that prevents the browser from trying to guess the file type.

5. Is this open source?

This is a private educational project for cybersecurity diplomas.
